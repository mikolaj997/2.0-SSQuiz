# 2.0-SSQuiz

A responsive e-learning application for studying English vocabulary with flashcards and short quizzes.

🇬🇧 English | 🇵🇱 [Polski](README.pl.md)

## Features

- Vocabulary quizzes divided into categories
- Interactive flashcards with terms and definitions
- Immediate answer feedback and score tracking
- Light and dark themes with a saved preference
- Responsive layout for desktop, tablet, and mobile devices
- Mobile navigation with a hamburger menu

## Technologies

- HTML5
- CSS3
- JavaScript
- Vue.js 3
- Bootstrap

The original application is built with Vue.js. Separate React and Angular versions are available on their respective branches.

## Branches

- `master` – main Vue.js version
- `dev` – active development branch
- `react` – React version
- `angular` – Angular version

## Running Locally

No build step or dependency installation is required.

1. Clone or download the repository.
2. Open the project directory in Visual Studio Code.
3. Open `index.html` with a local development server, such as the **Live Server** extension.

You can also open `index.html` directly in a modern web browser, although using a local server is recommended.
